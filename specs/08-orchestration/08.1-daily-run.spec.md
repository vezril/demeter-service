# 08.1 — Daily Run

## Intent

The scheduled job that ties every context together into one idempotent daily pass. It's the
top of the call graph: poll the flyer listing, diff it against the ledger, fetch only new or
changed flyers, normalize and persist their items, match against the watchlist, score
against history, decide, dedup, and deliver. Written so that a crash at any step is safe to
re-run (every store is idempotent, 03.3/03.4) and so that a single failing flyer never sinks
the whole run.

## Run shape (pinned sequence)

```
1. listing   = FlyerSource.flyers(postal, locale)          # 01.2
2. toFetch    = FlyerLedger.selectToFetch(listing, now)     # 03.4
3. for each flyer in toFetch (bounded concurrency):
     raw     = FlyerSource.items(flyer.id, …)               # 01.4  (archived first, 03.2)
     obs     = raw.items.map(assembleObservation)           # 02.6
     report  = ObservationStore.saveAll(obs, rawId)         # 03.3
     ledger.markFetched(flyer.id, window, rawId)            # 03.4
4. active    = ObservationStore.currentObservations(now)    # 03.3
5. matches   = watchlist.flatMap(w => active.matching(w))   # 04.3/04.4
6. for each match:
     stats   = rollingStats(history(key), window, now)      # 07.2
     verdict = scoreDeal(obs, stats, enrichment?)           # 07.3 (+06 if enabled)
     deal    = decide(match, watch, verdict)                # 05.1
     if new (05.2): sink.deliver(render(deal))              # 05.3/05.4/05.5
```

## Contract

- The run is a single `F[RunReport]`; it never throws. Per-flyer failures are collected into
  the report, not propagated.
- **Bounded concurrency** on the per-flyer fan-out (config, small — respect 01.6 rate limits).
- Enrichment (step 6) is optional and behind a flag; when off, `scoreDeal` runs on history
  alone.
- Idempotent end to end: running it twice in a day produces no duplicate observations and no
  duplicate alerts (dedup state persisted).

  Scenario: A normal run fetches only ledger-selected flyers

  Scenario: One failing flyer does not sink the run
