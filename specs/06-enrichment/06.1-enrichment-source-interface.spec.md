# 06.1 — Enrichment Source Interface

## Intent

Flipp tells you the *sale* price but rarely the *regular* price, and "is this a deal?"
needs both. Enrichment sources are retailer-direct backends that supply regular prices and
unit prices for a product lookup. They implement a distinct interface from `FlyerSource`
(01.1) because their job is different: given a product query, return current shelf/online
prices. Each is optional and independently degradable — if PC Express breaks, Flipp data
still flows.

## Contract

```scala
trait EnrichmentSource[F[_]]:
  def name: SourceName
  def merchantsCovered: Set[MerchantId]
  /** Look up current regular/online price for a query near a location. */
  def lookup(query: String, near: PostalCode, locale: Locale): F[Either[DealWatchError, List[EnrichedPrice]]]

final case class EnrichedPrice(
  merchantId: MerchantId,
  name: BilingualText,
  regularPrice: Option[Money],
  salePrice: Option[Money],
  unitPrice: Option[UnitPrice],
  source: SourceName,
  fetchedAt: Instant
)
```

- Enrichment is **best-effort and advisory**: a missing enrichment never blocks an
  observation or an alert; it only sharpens the deal verdict (07.3).
- Same 01.6 HTTP policy, same 00.5 error model. A `BotWall` from an enrichment source
  degrades just that source.
- Enrichment uses only anonymous / static-key endpoints — no logged-in, account-specific
  data (README non-goal).

```gherkin
Feature: Enrichment sources supply regular prices

  @boundary
  Scenario: A successful lookup returns regular and unit prices
    Given an enrichment source covering merchant 123
    When I look up "milk 4L" near a postal code
    Then I receive enriched prices with regular price and unit price where available

  @pure
  Scenario: A source declares which merchants it can enrich
    Given the PC Express source
    Then its covered merchants include the Loblaw banners it serves

  @boundary
  Scenario: An enrichment failure is non-blocking
    Given an enrichment source that returns an error
    When enrichment is attempted during a run
    Then the run continues
    And the affected observations simply lack enrichment
