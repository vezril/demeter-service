# 06.4 — Canadian Tire Enrichment Source

## Intent

Canadian Tire flyer data from Flipp is the worst-priced (mostly null prices, free text). CT's
own internal API — the one CanadianTracker uses — exposes regular prices per SKU, which is
exactly what you need to compute real discount depth for CT deals and to see through CT's
habit of inflating "regular" prices. This source is slower and more rate-sensitive than the
grocery ones, so it's fetched sparingly and cached hard.

## Endpoint (from CanadianTracker's approach; verify before depending)

CanadianTracker exercises the CT site's internal API in stages: products → SKUs → prices.
For enrichment we need the price-by-SKU/lookup path for a query near a store.

- **Status: shape known from the open CanadianTracker project; not executed live here.**
- Known characteristics: no login required, but **rate-sensitive** — back off aggressively,
  cache results for the flyer's whole validity window, and never fan out CT lookups in
  parallel.
