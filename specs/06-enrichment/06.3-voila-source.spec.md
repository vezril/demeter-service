# 06.3 — Voilà (IGA/Sobeys) Enrichment Source

## Intent

Adapt the Voilà backend, which powers Sobeys/IGA/Safeway online. This is your best
structured source for **IGA** regular and online prices (IGA.net checkout runs through Voilà
par IGA). Note the caveat baked into a scenario: Voilà online prices can differ from in-store
IGA flyer prices, so enrichment from here is a *reference*, not ground truth for the flyer
deal.

## Endpoint (from public reverse-engineering; verify before depending)

```
GET https://voila.ca/api/v5/products/search?term={TERM}&limit=20&offset=0&sort=favorite
Cookies: a VISITORID / global_sid session cookie is required
```

- **Status: not executed live in this research.** Pattern is consistent with known reports.
  The session cookie acquisition is the fragile part — model it as a small "establish
  session" step the adapter performs and can re-do on 401/expiry.

## Mapping

| Voilà field | EnrichedPrice |
|---|---|
| product name | `name` (fr/en per Accept-Language) |
| price | `regularPrice` |
| offer/promo price | `salePrice` |
| unit price | `unitPrice` |

## Gherkin

```gherkin
Feature: Voilà enrichment for IGA

  @boundary @contract
  Scenario: A products/search response maps to enriched prices
    Given a captured Voilà search response for "lait"
    When the adapter parses it
    Then each product yields an EnrichedPrice
    And prices are expressed in exact cents

  @boundary
  Scenario: A session cookie is established before searching
    Given no existing Voilà session
    When a lookup is attempted
    Then the adapter first establishes a session
    And then performs the search

  @boundary
  Scenario: An expired session is re-established once
    Given a search that returns 401 due to an expired session
    When the adapter handles it
    Then it re-establishes the session and retries once
    And a second 401 degrades the source

  @pure
  Scenario: Voilà prices are marked as an online reference, not flyer truth
    Given an EnrichedPrice from Voilà
    Then its provenance marks it as an online reference price
    And 07 treats it as advisory relative to the flyer observation
