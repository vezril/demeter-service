# 06.2 — PC Express Enrichment Source

## Intent

Adapt Loblaw's PC Express backend to `EnrichmentSource`. This covers Maxi and Provigo (your
Quebec-relevant banners) plus No Frills, Loblaws, Superstore, Zehrs, etc. It's the
highest-value enrichment because it exposes regular prices and unit prices Flipp omits, and
it's widely described as the most tractable retailer backend to integrate.

## Endpoint (from public reverse-engineering; verify before depending)

```
POST https://api.pcexpress.ca/product-facade/v3/products/search
Headers:
  Site-Banner: {maxi|provigo|superstore|nofrills|loblaw|zehrs|…}
  X-Apikey: {static key harvested from the site/app; no user login}
  Content-Type: application/json
Body (shape):
  { "pagination": {"from": 1, "size": 20},
    "banner": "maxi", "storeId": "…", "lang": "fr"|"en",
    "term": "lait", "cellId": "…" }
```

- **Status: not executed live in this research.** The shape is consistent with known public
  reports. The `@contract` scenario exists precisely to confirm/deny it at build time.
- The `X-Apikey` is a static, app-embedded key (not a user credential). Treat it as config
  the operator supplies; do not hardcode it in source.

## Mapping to EnrichedPrice

| PC Express field | EnrichedPrice |
|---|---|
| product name (per `lang`) | `name` |
| regular price | `regularPrice` |
| sale/deal price if present | `salePrice` |
| comparison/unit price | `unitPrice` |
| banner → merchant | `merchantId` |
