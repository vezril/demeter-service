# 01.2 — Flipp `flyers` Endpoint Adapter

## Intent

Adapt the Flipp "which flyers are live near this postal code" endpoint to the `FlyerSource`
interface. This is the entry point of the daily run: it's how the orchestrator learns which
flyers exist so 03.4 can diff them and decide what to fetch in full.

## Endpoint (verified live 2026-07-26)

```
GET https://backflipp.wishabi.com/flipp/flyers
      ?locale={en-ca|fr-ca}
      &postal_code={CANONICAL_NO_SPACE}     e.g. H2X1Y6
```

- No auth key required (verified).
- Returns JSON: top-level `refreshed_at` (string, `"2026-07-24 14:49:12 -0400"`) and
  `flyers` (array). For H2X1Y6 this returned **121 flyers across 95 merchants**.
- Also returns `category_sort_csv` (a static-ish category ordering) — not needed by the
  domain, ignore it.

### Flyer object fields we consume (others ignored)

| JSON field | Domain | Notes |
|---|---|---|
| `id` | `FlyerId` | Long |
| `merchant_id` | `MerchantId` | Int |
| `merchant` | `Merchant.name` | string, e.g. `"Canadian Tire"`, `"RONA & RONA +"` |
| `name` | `Flyer.name` | e.g. `"Weekly Flyer"`, `"Quebec"` |
| `valid_from` / `valid_to` | window | ISO-8601 with offset |
| `postal_code` | echo | sanity-check it matches request |
| `locale` / `language` | `Locale` | echo |
| `available_from` / `available_to` | — | availability vs validity; keep in raw only |

## Contract

- Builds the query string from a `PostalCode` (canonical, no space) and `Locale`
  (`queryValue`). A caller cannot pass a malformed postal code — the type prevents it.
- On 2xx: archive raw bytes, decode via 01.5, return `RawFlyerListing`.
- On non-2xx / timeout / transport: map to the corresponding 00.5 error. A 403 or a
  Cloudflare challenge body maps to `BotWall`, not a generic `HttpStatus`.
- The adapter does **no** filtering by merchant. It returns all flyers; selecting which to
  fetch is the orchestrator's job (08.1). Keeping the adapter dumb keeps it testable.

## Notes

- The `merchant` name lives on the flyer object here (unlike per-flyer *items*, where it's
  often null — see 01.4). Capture it now; it saves a join later.
- `@contract` on the decode scenario: when Flipp renames a field, this is the test that goes
  red first. Keep the fixture fresh-ish, but a stale fixture failing is itself the signal.
