# 03.2 — Raw Response Store

## Intent

Archive the exact bytes of every upstream fetch before anything parses them. This is the
foundation of the "replayable, back-fillable" property the whole system depends on. When a
decoder bug is found (and with undocumented endpoints, it will be), you fix the pure parser
and re-run normalization over the archive — no re-fetching, no lost data, no re-hitting a
fragile endpoint.

## Contract

```scala
trait RawResponseStore[F[_]]:
  def put(raw: RawResponse, source: SourceName, kind: ResponseKind,
          postal: PostalCode, locale: Locale): F[Either[DealWatchError, RawResponseId]]
  def get(id: RawResponseId): F[Either[DealWatchError, RawResponse]]
  def stream(source: SourceName, kind: ResponseKind): fs2.Stream[F, (RawResponseId, RawResponse)]
```

- `put` stores bytes verbatim plus metadata and a sha256. If an identical body
  (same sha256, source, kind, postal, locale) was stored within a dedup window, it may
  return the existing id rather than duplicating — configurable, off by default for safety.
- `get` returns the exact bytes originally stored — byte-for-byte, no re-encoding.
- `stream` drives replay (03.1's rebuild scenario, 02.6 back-fill).
