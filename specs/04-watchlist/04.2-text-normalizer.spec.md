# 04.2 — Text Normalizer (Matching)

## Intent

The shared text-normalization function used both to build match keys and to prepare watch
terms, so a term and an item name are compared on equal footing. Accent-folding is the
crucial piece for Quebec data: "café" must match "cafe", "crème" must match "creme". Pure,
total, and reused by 02.7 (product key) so normalization is defined in exactly one place.

## Normalization steps (ordered, pinned)

1. Unicode NFKD + strip combining marks (é → e, ç → c).
2. Lowercase.
3. Replace punctuation and symbols with spaces (keep alphanumerics).
4. Collapse runs of whitespace to a single space; trim.
5. Drop a configurable stopword set (both languages: "de", "the", "avec", "with", "&").
6. Result is a normalized token list (and a joined string form).
