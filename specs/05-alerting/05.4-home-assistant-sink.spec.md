# 05.4 — Home Assistant Sink

## Intent

Deliver alerts into your self-hosted Home Assistant, the primary alert surface. Two viable
mechanisms; the sink supports whichever you configure: (a) POST to a HA webhook, or (b)
publish to an MQTT topic HA subscribes to. Either way HA automations handle the actual
notification routing (phone, speaker, dashboard). This is a boundary unit — verified against
a fake HA endpoint, not a live one.

## Contract

```scala
trait AlertSink[F[_]]:
  def name: SinkName
  def deliver(alert: Alert): F[Either[DealWatchError, Unit]]

final class HomeAssistantSink[F[_]](cfg: HaConfig) extends AlertSink[F]
```

- **Publish is a permissioned action** in spirit (README: alerts to *your own* HA are fine;
  this never posts anywhere the user didn't configure). The target URL/topic is config, never
  derived from flyer content.
- Delivery failures are retriable via 01.6 policy (HA might be momentarily down); a
  persistent failure falls through to a fallback sink (05.5), it never crashes the run.
- The sink records what it delivered so 05.2's dedup state can be persisted.

## Gherkin

```gherkin
Feature: Deliver alerts to Home Assistant

  @boundary
  Scenario: A webhook delivery posts the structured alert
    Given a Home Assistant webhook sink
    When I deliver an alert
    Then a POST is made to the configured webhook URL
    And the body is the structured alert JSON

  @boundary
  Scenario: An MQTT delivery publishes to the configured topic
    Given an MQTT-configured HA sink
    When I deliver an alert
    Then a message is published to the configured topic

  @boundary
  Scenario: A transient HA outage is retried then falls back
    Given HA returns 503 on every attempt
    And a fallback sink is configured
    When I deliver an alert
    Then delivery is retried per policy
    And on exhaustion the alert is handed to the fallback sink

  @boundary
  Scenario: The sink never posts to a target from flyer content
    Given an alert whose item text contains a URL
    When I deliver it
    Then the delivery target is the configured HA endpoint only
