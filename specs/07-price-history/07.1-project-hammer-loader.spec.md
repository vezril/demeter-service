# 07.1 — Project Hammer Loader

## Intent

Seed price history from Jacob Filipp's open Project Hammer dataset so "is this a good deal?"
has a baseline from day one, before your own polling has accumulated weeks of data. Hammer
covers Voila, T&T, Loblaws, No Frills, Metro, Galleria, Walmart, and Save-On-Foods with daily
prices from 2024-02-28 onward, and — crucially — carries both `current_price` and `old_price`,
letting you distinguish an advertised sale from a quiet drop. This is a one-off / periodic
batch loader, not part of the daily run.

## Contract

```scala
trait HammerLoader[F[_]]:
  def load(productCsv: Path, rawCsv: Path): F[Either[DealWatchError, LoadReport]]

final case class LoadReport(products: Int, priceRows: Int, skipped: Int)
```

- Loads the two-file (product + raw) form or the SQLite form; joins on the product id.
- Maps Hammer vendors to our `MerchantId`s where they overlap (Metro, Voila→IGA-ish, etc.)
  and derives a `ProductKey` via 02.7 so Hammer history and our own observations share a key
  space **where the mapping is sound**. Where Hammer's own docs warn the id is unstable or UPC
  matching is fuzzy (Loblaws/NoFrills/T&T/Voila), those rows are loaded but flagged
  lower-trust so 07.2 can weight them down.
- Loaded history is marked with `source = hammer` provenance so it's never confused with
  first-party observations.
