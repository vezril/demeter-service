# 02.2 — Multi-Buy Parser

## Intent

Turn `"2 for $5"`, `"3/$5.00"`, `"2 pour 5 $"`, `"buy 2 get 1 free"` into a usable per-unit
`Money` so the watchlist can compare a multibuy promo against a single-unit target price. A
"2 for $5" milk at $2.50/unit may beat a "$2.99" milk elsewhere — without this, that deal is
invisible. Pure function; leans on 02.1 for the money token and 00.1 for the half-even
division.

## What it handles

- `N for $X` / `N/$X` / `N pour X $` → unit price = `X / N` (half-even, 00.1).
- `buy N get M free` → effective unit over the `N+M` items you leave with, at the item's own
  single price (needs a base price; if absent, emit a structured promo with no unit price).
- Mixed: `"2 for $5.00, save $1.98"` → parse the `2 for $5.00`, ignore the savings tail
  (it's marketing, and it's derivable).
- Emits a `MultiBuy` describing the structure *and* the derived unit price, so 02.6 records
  `PriceBasis.MultiBuyUnit` and 07 can weight it appropriately.

## Contract

```scala
final case class MultiBuy(
  quantity: Int,
  bundlePrice: Option[Money],     // "$5" in "2 for $5"; None for pure BOGO
  freeQuantity: Int,             // M in buy-N-get-M-free; 0 otherwise
  unitPrice: Option[Money]        // derived; None when underivable
)

def parseMultiBuy(text: String, basePrice: Option[Money], locale: Locale): Option[MultiBuy]
```

- Returns `None` when the text has no multibuy structure at all (so 02.6 can fall through to
  scalar/percent/parsed-text handling).

## Notes

- The `3/$5 → 167` case is where half-even earns its keep: `500/3 = 166.66…`. Pin it, and
  add a mutation-testing note — a naive `round` vs `floor` swap must be caught.
- BOGO-without-base is common in Canadian Tire data (no `current_price`). Emitting structure
  with a `None` unit price still lets the watchlist flag "this thing is on a BOGO" even when
  we can't price it — better than silence.
